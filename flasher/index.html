Key Box MCU 测试固件

ESP32-C6，经 USB（IO12 / IO13 原生 USB 串口）用 Chrome / Edge 刷写。

浏览器不支持 Web Serial，请用桌面版 Chrome 或 Edge。 需要 HTTPS 或 localhost 才能使用串口。

步骤

  1. USB 接上模组，点 CONNECT，选 USB JTAG/serial debug unit。
  2. 连不上时：按住 SERVICE（IO9 / BOOT），点一下 RESET（EN），松开 SERVICE，再连接。
  3. 选 Install，建议勾选擦除。完成后按 RESET 运行。
  4. LED（IO7）每秒短闪一次 = 等待蓝牙配网。手机装 Espressif 的 ESP BLE Provisioning App， 选设备 KEYBOX_xxxxxx，PoP 填 keybox123，选 Wi-Fi 并输入密码。
  5. LED 快闪 = 正在连 Wi-Fi，常亮 = 已连上。浏览器打开 http://keybox-xxxxxx.local/ 或串口日志里的 IP，即可看到测试页面。
  6. 重新配网：网页上点“重新配网”，或按住 SERVICE 5 秒。

串口日志：连接后在本页菜单里选 Logs & Console（115200）。
